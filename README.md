# Challenge Conversor de Moneda - 2025

Este proyecto es un conversor de monedas desarrollado en Java como parte de un challenge de Alura. La aplicación se ejecuta en la consola y permite a los usuarios convertir entre diferentes divisas utilizando tasas de cambio obtenidas de una API externa.

## 🚀 Características Principales

* **Aplicación de Consola:** Interfaz de usuario simple y directa a través de la terminal.
* **Consumo de API:** Se conecta a una API de tasas de cambio para obtener valores en tiempo real.
* **Conversiones Disponibles:** El menú principal ofrece las siguientes opciones de conversión:
    1.  Dólar a Peso Argentino
    2.  Peso Argentino a Dólar
    3.  Euro a Peso Argentino
    4.  Peso Argentino a Euro
    5.  Dólar a Real Brasileño
    6.  Real Brasileño a Dólar
    7.  Dólar a Peso Colombiano
    8.  Peso Colombiano a Dólar

## 🛠️ Tecnologías Utilizadas

* **Java:** Lenguaje principal del proyecto.
* **IntelliJ IDEA:** IDE de desarrollo.
* **Git y GitHub:** Control de versiones y alojamiento de código.
* **API Externa:** Para obtener las tasas de cambio actualizadas.

## 🏁 Cómo ejecutar el proyecto

1.  **Clonar el repositorio:**
    ```bash
    git clone https://github.com/JohnnyBenitez888/challengeconversor2025.git
    ```


2.  **Configurar la API Key:**
    * Este proyecto utiliza la API de ExchangeRate para obtener las tasas de cambio actuales. Se requiere una clave de API válida, que se puede obtener registrándose en https://www.exchangerate-api.com/.
    * Reemplazar `"API_KEY"` en la Interface `Keys.java` con la clave de API obtenida.
       

3.  **Ejecutar la aplicación:**
    * Abrir el proyecto en IntelliJ IDEA.
    * Ejecutar el método `main` en la clase `Principal.java`.
